# 大学生健康协会管理系统

为协会提供的内部管理系统:**管人**(会员与部门)、**管事**(活动、签到与活动材料归档)、**管信息**(公告与统计)。全中文界面,电脑手机都能用,单机即可运行,预置演示数据。

## 技术栈

- **前端** `web/`:Vue 3 + Element Plus(中文)+ ECharts + axios + vue-router
- **后端** `server/`:Node.js 24 + Express 4 + `node:sqlite`(Node 内置,零原生编译依赖)+ JWT
- **数据库**:单文件 SQLite(`server/data/app.db`),备份 = 复制文件

## 安装(每台电脑只需一次)

```bash
# 1. 后端依赖
cd server && npm install

# 2. 前端依赖
cd ../web && npm install
```

## 运行方式一:日常使用(生产模式,一个端口)

```bash
cd web && npm run build        # 构建前端(改动前端后需重新执行)
cd ../server && npm start      # 启动服务,浏览器打开 http://localhost:3000
```

## 运行方式二:开发调试(热更新)

```bash
# 终端一:后端(端口 3000)
cd server && npm run dev

# 终端二:前端(端口 5173,浏览器打开 http://localhost:5173)
cd web && npm run dev
```

## 现场扫码签到(重要)

1. 现场签到请用**生产模式**运行(监听 0.0.0.0),手机与运行系统的电脑连**同一个 Wi-Fi**;
2. 干部打开活动详情 → 管理区 → 点"全屏投屏",屏幕显示动态二维码(每 60 秒自动刷新,截图最多 2 分钟失效)+ 6 位数字码兜底;
3. 会员手机扫码直达签到页,登录后一键签到;
4. 二维码自动使用电脑的局域网地址;如识别错误,可设置环境变量 `LAN_IP` 指定,例如(Windows):`set LAN_IP=192.168.1.100 && npm start`。

## 数据与备份

- 全部数据在 `server/data/`(`app.db` 数据库 + `uploads/` 附件 + `secret.key` 签名密钥);
- **备份 = 复制整个 `server/data/` 目录**;建议每周复制一次,换届交接前必备份;
- 重置演示数据:停止服务后删除 `server/data/app.db`(及 `-wal`/`-shm` 文件),重新启动即自动重建。

## 常见问题

- 启动时出现 `node:sqlite` 实验性警告:不影响功能,可用 `node --no-warnings src/index.js` 静默;
- 扫码后手机打不开页面:检查手机与电脑是否同一 Wi-Fi、电脑防火墙是否放行 3000 端口;
- 忘记超管密码:删除 `server/data/app.db` 重建(会清空全部数据,先备份!);
- 换电脑迁移:复制整个项目目录(或至少 `server/data/`),新电脑重新 `npm install`。
